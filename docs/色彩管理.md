# 色彩管理约定

> **一句话**：全部在线性空间里合成，最后一步才转成 sRGB 给屏幕看。
>
> 适用：Harmony（2D 角色）+ Blender（3D 环境）+ AE（合成）。

---

## 一、为什么要线性

sRGB 带 gamma 曲线，是**给屏幕看的**。在 sRGB 空间里做加法、乘法、混合，
结果在物理上是不对的：

- 两个颜色相加 ≠ 你看到的相加；
- 高光容易截断；
- alpha 边缘会出现黑边/白边。

**线性空间里，数值和光量成正比**，相加相乘才有物理意义。

---

## 二、四个环节怎么设

### 1. Harmony · Scene Settings > Colour

| 项 | 值 |
|---|---|
| Working Colour Space | **`Linear Rec.709 (sRGB)`** |
| Processing Bit Depth | **`32 bits per channel (float)`** |
| Read Toon Boom Drawings Using sRGB | **保持勾选**（画稿本身是 sRGB） |

### 2. Harmony · Write 节点

| 项 | beauty / line | normal / depth |
|---|---|---|
| Colour Space | `Linear Rec.709 (sRGB)` | 同左 |
| Image Format | **`EXR`** | **`EXR`** |
| Colours | **`Colour + Alpha`** | Colour |
| Depth | **32 bits (float)** | 16 或 32 |
| Compression | **`DWAA`** | **`ZIP`** |

> **为什么 normal/depth 用 ZIP**：DWAA 是有损压缩，法线上的误差会变成重打光的色带，
> 深度上的误差会变成台阶。这两类是「数据」不是「图像」。

### 3. Blender

| 项 | 值 |
|---|---|
| 输出格式 | **OpenEXR**（不要 PNG） |
| Color Management | **不用特别设** |

**原因**：Blender 存 EXR 时写的是**场景线性**数据，`View Transform`（AgX/Filmic）
只影响屏幕显示和 PNG 输出，**不影响 EXR**。

> 所以：合成素材从 Blender 一律出 EXR，出 PNG 会被套上 AgX，颜色就变了。

### 4. AE

| 项 | 值 |
|---|---|
| Project Settings > Color | **32 bits per channel** |
| EXR 素材的 Interpret Footage | **Linear**（或 Linear Rec.709） |
| 输出（交付） | 最后加一个**显示变换**转 sRGB |

---

## 三、数据流

```
Harmony（画稿是 sRGB）
   │  转成 Linear Rec.709
   ▼
线性 EXR（32-bit）
   │
   ├──────────────┐
   ▼              ▼
Blender 线性 EXR   AE 合成（32-bit 线性）
                    │
                    ▼
              显示变换 → sRGB
                    │
                    ▼
                 成片
```

**中间全程线性，只有最后一步转 sRGB。**

---

## 四、常见错误

| 错误 | 后果 |
|---|---|
| 在 sRGB 空间里合成 | 颜色混合不对、高光断裂 |
| 用 PNG 当合成素材 | 已经被 gamma 处理过，救不回来 |
| AE 工程设成 8-bit | 高光截断、渐变出条纹 |
| 把 EXR 当 sRGB 读 | 画面发灰/发白 |
| normal/depth 用 DWAA | 重打光有色带、深度有台阶 |
| **对数据通道做色彩变换** | 数值错乱（深度不是亮度，法线不是颜色） |

---

## 四·五、数据通道的特例

`normal`、`depth`、`matte`、`mist` 这些**不是画**，是测量值。

| 规则 | 说明 |
|---|---|
| **不要做任何色彩变换** | 不要转到 sRGB/ACES，原样存 |
| **不要用有损压缩** | ZIP，不是 DWAA |
| **不要加滤镜** | 模糊、调色、风格化全部禁止 |
| 在 AE 里 | 当作 Linear 或 Raw 读，只当遮罩/参数 |

**判断方法**：如果这个通道的值不是「颜色」，就别碰它的颜色。

---

## 五、怎么验证对不对

**灰阶测试**（最直观）：

1. 渲一张**线性渐变**（黑到白）的图；
2. 在 AE 里看，应该是**平滑的**；
3. 如果中间出现明显的「亮暗分界」或「条纹」，说明色彩空间搞错了。

**另**：把同一张图分别按 sRGB 和 Linear 解释，对比一下——差别很大，就能看出哪个对。
