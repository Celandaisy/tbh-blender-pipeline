## 交接说明（给下一个接手的人 / AI）

1. 本文解决的不是「怎么叠层」，而是「**怎么让 2D 角色看起来真的站在 3D 世界里**」。
2. 核心判据只有一条：**遮住角色轮廓，分不清哪部分是 3D、哪部分是 2D**。
3. 第 6 节「风格匹配」是整篇的成败点，其他都是配套。

## 0. TL;DR

- 合成要处理三件事：**遮挡、受光、大气/景深**。
- 受光的核心是**风格匹配**：3D 的 toon 阶梯、rim、描边，必须和 2D 的 Normality toon shading 对得上。
- 法线重打光首选 **Normality**（AE，免费）；若效果不够，**Autograph 的 Shadertoy/GLSL 节点**可以自定义，且能拿到相机矩阵。
- 遮挡用 **Blender 逐帧 matte**。
- 色彩管理与 Alpha 是「不做好就前功尽弃」的两块基础设施。

---

## 1. 合成目标与判据

### 1.1 什么叫「融进去」

不是「角色在背景前面」，而是：

- 角色的**明暗**跟环境一致（同一束光）；
- 角色的**影子**落对地方、颜色对；
- 角色的**边缘**（线、rim、抗锯齿）和背景同一套语言；
- 角色**越远越淡**，有大气透视；
- 相机运动时，两者**同步视差**，不滑不飘。

### 1.2 验收判据（可操作）

| 测试 | 做法 | 通过标准 |
|---|---|---|
| **轮廓测试** | 眯眼/缩小到 30%，看能否分辨哪部分是 2D | 分不清 |
| **受光测试** | 遮住角色，只看背景；再遮住背景，只看角色，对比明暗方向 | 明暗交界线走向一致 |
| **运动测试** | 播放，盯角色脚底与地面接触点 | 不滑、不飘 |

## 2. 叠层结构

```
┌─────────────────────────────────────┐
│  最终调色 / LUT / 颗粒               │
├─────────────────────────────────────┤
│  大气透视 / 雾 / 深度 DOF            │  ← 用 Z pass
├─────────────────────────────────────┤
│  前景遮挡 matte（Blender 逐帧）      │  ← 挡住角色
├─────────────────────────────────────┤
│  2D 角色层（TBH）                    │
│    ├─ 底色 + alpha                  │
│    ├─ 法线图（重打光用）             │
│    ├─ 高度图（可选）                 │
│    └─ AO / 接触阴影                  │
├─────────────────────────────────────┤
│  3D 背景（Blender EXR）              │
│    ├─ Beauty                        │
│    ├─ Z / 深度                      │
│    ├─ 法线（可选）                   │
│    ├─ 阴影（可选）                   │
│    └─ Object Index / Cryptomatte     │
└─────────────────────────────────────┘
```

**关键原则**：角色层与背景层**各自独立可控**；所有「融合」效果都在它们之上叠加，不烘死在任一层里。

## 3. 遮挡（方案已定）

### 3.1 做法

Blender 单独导出前景物体（建筑、树、道具）的 matte，在合成软件中遮住 2D 角色。

### 3.2 要求

- **逐帧**导出——相机一动，前景 alpha 每帧都在变；
- 带**抗锯齿**，否则角色边缘被硬切；
- 若角色的**倒影/阴影**也要被遮挡，matte 必须覆盖该区域；
- 与角色层使用**相同分辨率与宽高比**。

### 3.3 实现路径

- Blender：Object Index / Cryptomatte / 单独渲染层，输出为带 alpha 的 EXR 或 PNG。
- 合成：把 matte 作为角色层的 Alpha Matte（或相乘）。

---

## 4. 阴影

### 4.1 角色自身 AO

- 来自绑定阶段烘焙（3D 排开身体部件后镜像/翻下），压平到 2D。
- **视角无关**，相机怎么动都不会散。
- 与角色共用 master peg，天然同步。

### 4.2 角色在地面的投影

- 大部分情况用 4.1 的接触阴影即可。
- 只有**长投影 / 硬光**镜头才需要额外处理：
  - 方案 A：Blender 里放「只投影不渲染」的代理平面（alpha 裁剪），用真实灯光投一次；
  - 方案 B：合成里用 2D 伪影 + 手动偏移（低成本，但相机倾斜/弧线时会露馅）。

### 4.3 Blender 环境自阴影

- 属于 3D 背景的一部分，单独 pass 输出，合成里可调强度。

## 5. 受光：法线重打光

### 5.1 原理

用角色自带的**法线图**，在 2D 层上模拟一束方向光，做出明暗交界线与 rim light。本质是「屏幕空间的 3D 受光」。

### 5.2 Normality 流程（AE）

1. 准备法线图，与角色底图**同尺寸**；
2. 预合成（Pre-Compose，勾 Move all attributes），法线层隐藏；
3. Normality 中指定法线层，建点光 / 方向光；
4. 调 **rim light** 颜色与角度；
5. 开 **toon shading**，选阴影/中间调/高光色；
6. 可选：半调、噪点、Deep Glow。

> 参考：[80.lv · 2D 角色 3D 打光教程](https://80.lv./articles/learn-how-to-set-up-3d-lighting-for-2d-characters-with-this-after-effects-tutorial)

### 5.3 参数

| 参数 | 作用 | 匹配对象 |
|---|---|---|
| 光方向 | 明暗交界线走向 | 3D 场景主光 |
| 阶数 | 明暗分几档 | 3D toon ramp 档数 |
| 阈值 | 分界线位置 | 3D 的 terminator |
| 阴影色 | 暗部色相 | 3D 阴影色（常带冷偏移） |
| rim 颜色/宽度 | 边缘光 | 环境反射色 |
| 高光 | 是否要 specular | 3D 是否给高光 |

### 5.4 常见问题

- **光方向随相机转**：相机 roll/tilt 时屏幕空间光方向会变，需逐镜头或逐帧调整。
- **边缘脏**：法线图边缘与 alpha 不匹配，重打光会在边缘出黑边；给法线图做边缘扩张。
- **切线空间不对**：法线图必须是切线空间（tangent space），否则方向全错。

## 6. 风格匹配（**成败点**）

### 6.1 七个维度

| 维度 | 3D 环境 | 2D 角色 | 不一致时的观感 |
|---|---|---|---|
| 光方向 | 场景主光 | light direction | 影子反向，立刻穿帮 |
| 明暗阶数 | toon ramp 档数 | toon shading 档数 | 一边 3 档一边 2 档 |
| 阈值位置 | terminator | threshold | 亮暗比例不同，体积感不对 |
| **阴影色相** | 常为灰/黑 | 可调紫/蓝偏移 | 2D 偏冷、3D 偏灰，最明显的「两套东西」 |
| rim light | 环境反射色 | rim 颜色/宽度 | 角色没有边缘光，像浮在背景上 |
| 线稿 | Solidify/Freestyle | 手绘线 | 线宽、线色、收尖方式不同 |
| 大气透视 | 雾/景深/去饱和 | 默认没有 | 角色「太清楚」 |

### 6.2 校准球（推荐）

1. 在 3D 场景里、**角色所在的位置**放一个球（与环境同款 NPR 材质）；
2. 渲一张出来——这张图就是「这个位置、这束光下，3D 会怎么明暗」；
3. 在合成里调角色，直到明暗交界线、阴影色、rim 都与球一致；
4. 最终渲染时隐藏球，或单独一个 pass。

**这把「风格匹配」从凭感觉变成了有参照物的比对。**

### 6.3 3D 光照复杂度约束

Normality 只能给**一个**光方向。若 3D 场景是三灯 + GI，2D 永远只能单光凑，永远差一点。

**生产规则**：把 3D 主光做成**绝对主导**（一个太阳 + 弱环境补光），让单方向重打光可复现。

## 7. 大气透视与深度融合

### 7.1 作用

角色越远越淡、越偏环境色——这是 2D/3D 融合里**最便宜也最有效**的一招。

### 7.2 做法

- 用 Blender 的 **Z pass** 做深度驱动的雾/去饱和；
- 角色没有逐像素深度（TBH 不输出 Z），可用**固定深度**（角色所在平面）近似；
- 相机同步已给出角色的空间位置，可直接算出「它该有多远」。

### 7.3 注意

- 雾的颜色要与 3D 背景的远景色一致；
- 不要过度，角色太淡会「脏」。

## 8. 色彩管理

### 8.1 三方的色彩空间

| 环节 | 常见输出 | 空间 |
|---|---|---|
| Blender | EXR | 线性（scene-referred） |
| TBH | PNG | sRGB（display-referred） |
| 合成软件 | 工程设置 | 可线性可 sRGB |

### 8.2 推荐管线（待验证）

1. 统一到**线性**工作空间合成；
2. TBH 的 sRGB 层先转线性；
3. Blender EXR 已是线性，直接用；
4. 最终输出时转显示空间。

### 8.3 检查点

- 暗部是否发灰/发绿；
- 高饱和色是否溢出；
- 与参考图对比，而不是相信眼睛。

## 9. Alpha

### 9.1 premultiplied vs straight

- **premultiplied**：颜色已乘 alpha，边缘不会出黑边，但修改 alpha 要小心；
- **straight**：颜色与 alpha 独立，边缘计算更灵活，但混合不对会出白边/黑边。

### 9.2 检查方法

- 把角色放在**纯白**和**纯黑**背景上各看一次；
- 边缘出现黑边 → premult 用了 straight 的算法；
- 边缘出现白边 → 反之。

## 10. 运动模糊与景深

### 10.1 一致性策略

| 策略 | 优点 | 缺点 |
|---|---|---|
| 两边都不开 | 最稳，风格统一 | 运动时略「硬」 |
| 只合成侧加 | 统一控制 | 需要手调 |
| 两边都开 | 最真实 | 2D 无对应模糊，易割裂 |

### 10.2 深度 DOF

- 用 Blender Z pass 驱动景深；
- 角色用固定深度（所在平面）近似；
- 角色若在焦外，注意边缘与背景的融合。

## 11. 工具选型

### 11.1 对比

| 维度 | AE | Autograph | Blender 合成 |
|---|---|---|---|
| 法线重打光 | Normality（成熟） | GLSL 自定义 | 节点/OSL |
| 3D 相机支持 | 有限 | **原生** | 原生 |
| GLSL | 无原生 | **Shadertoy 节点** | 无（OSL 另说） |
| 学习成本 | 低 | 中 | 中 |
| 适合 | 2D 为主 | 3D 感知合成 | 全 3D 流程 |

### 11.2 什么时候切 Autograph

- 需要**相机感知**的效果（深度雾、屏幕空间光随相机转、3D 遮挡判断）；
- Normality 的 toon 效果不够，需要自定义着色；
- 镜头里 3D 关系复杂，AE 的 2D 假影撑不住。

## 12. 自定义 GLSL（Autograph Shadertoy）

### 12.1 为什么可行

Autograph 的 **Shadertoy 节点**支持 GLSL 片元着色器，并且**把合成相机的矩阵作为 uniform 传入**：

| Uniform | 用途 |
|---|---|
| `iResolution` | 分辨率 |
| `iChannel0..3` | 输入贴图（底色/法线/深度） |
| `iCamViewMatrix` | 世界 → 视图 |
| `iCamInvViewMatrix` | 视图 → 世界 |
| `iCamProjMatrix` / `iCamInvProjMatrix` | 投影 / 反投影 |
| `iTime` / `iFrame` | 时间 |

来源：[Autograph 文档 · Shadertoy](https://help.maxon.net/ag/en-us/Content/html/Modifier_image_shadertoy.html)

### 12.2 最小受光 shader 思路

```glsl
void mainImage(out vec4 fragColor, in vec2 fragCoord) {
    vec2 uv = fragCoord / iResolution.xy;

    vec4 base = texture(iChannel0, uv);           // 角色底色
    vec3 n    = texture(iChannel1, uv).rgb * 2.0 - 1.0;  // 法线
    float d   = texture(iChannel2, uv).r;         // 深度（可选）

    // 屏幕空间光方向（相机 roll 时用 iCamViewMatrix 旋转世界光得到）
    vec3 L = normalize(vec3(0.4, 0.8, 0.3));

    float ndl  = max(dot(n, L), 0.0);
    float band = smoothstep(0.45, 0.55, ndl);     // toon 阈值

    vec3 shadowTint = vec3(0.55, 0.50, 0.75);     // 阴影带冷偏移
    vec3 col = mix(base.rgb * shadowTint, base.rgb, band);

    fragColor = vec4(col, base.a);
}
```

### 12.3 GLSL 坑（Autograph 文档明确列出）

- 浮点后缀 `1.0f` **非法**，写 `1.0`；
- 没有 `saturate()`，用 `clamp(x, 0.0, 1.0)`；
- `pow`/`sqrt` 不要喂负数，加 `abs()` 或 `max(0.0, ...)`；
- 不要 `mod(x, 0.0)`；
- 变量必须初始化；
- 函数名不要和变量重名；
- **多 pass 和声音不支持**（多 pass 可以链多个 Shadertoy 节点模拟）。

### 12.4 什么时候值得写

- Normality 的 toon 分档不够细；
- 需要**按深度**调光（远处雾、近处实）；
- 需要**相机 roll 时自动转光向**；
- 需要把「法线 + 高度 + 深度」放进同一个 shader 里统一处理。

> **状态：待定**。先在 AE + Normality 上把镜头跑通，只有确实不够时才切 Autograph + GLSL。

## 13. 每镜头检查清单

- [ ] 角色层与背景层分辨率 / 宽高比一致
- [ ] 前遮挡 matte 逐帧、带抗锯齿
- [ ] 角色阴影/倒影被 matte 正确覆盖
- [ ] 光方向与 3D 主光一致
- [ ] 明暗阶数与 3D toon ramp 档数一致
- [ ] 阴影色相与 3D 阴影一致
- [ ] rim light 颜色来自环境
- [ ] 边缘无黑边/白边
- [ ] 大气透视与背景远景色一致
- [ ] 运动时脚底不滑
- [ ] 轮廓测试：眯眼看不出接缝

## 14. 排错

| 现象 | 可能原因 | 对策 |
|---|---|---|
| 角色像贴纸 | 光方向/阶数/阴影色不一致 | 用校准球比对 |
| 边缘黑边 | premult/straight 混用 | 统一 Alpha 方式 |
| 边缘白边 | 同上 | 同上 |
| 角色浮在背景上 | 缺 rim light / 大气透视 | 补边缘光 + 距离雾 |
| 影子方向错 | 光方向未随相机调整 | 逐镜头校准 |
| 角色「太清楚」 | 无景深/无雾 | 加深度驱动效果 |
| 相机转时受光错 | 屏幕空间光方向未更新 | 用相机矩阵重算 L |
