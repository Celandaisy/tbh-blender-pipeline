# 使用说明 · Harmony → Blender 相机与角色同步

  这份是**操作手册**：从建场景到导入 Blender，一步步照做就行。
  原理和验证记录在 `TBH25-Blender-摄像机同步-完整技术文档.md`，这里不重复。

---

## 〇、一次性准备

### 1. 安装两个 Blender 插件

`Edit   Preferences   Add-ons   Install...`，分别选：

```
tools/harmony_camera_importer.py
tools/harmony_character_importer.py
```

装完在列表里**勾选启用**。

### 2. 验证装好了

`File   Import` 里应该有两项：

```
Harmony Camera (.json)
Harmony Character (.json)
```

---

## 一、命名规范（必须遵守）

脚本靠**节点名字**找数据，名字错了会提示。

| 节点 | 名字 | 类型 |
|---|---|---|
| 底模（3D 环境代理） | **`model`** | Drawing |
| 角色 | **`character`** | Drawing 或 Group |
| 相机 | **场景默认相机** | 不用改名 |

**父 Peg 的名字无所谓**——脚本读的是累积世界矩阵。

  **角色是复杂合成怎么办？**
  把**最顶层的那个 Peg** 命名为 `character`（只改它的名字，不用动里面的合成）。
  脚本读它的世界矩阵，整条链上的变换都会带进去。
  命名它下面的 Group 通常也行，但 **Peg 最直接、最不容易误会**。

---

## 二、Peg 设置

### 底模（`model` 上面的 Peg）

| 项 | 设置 | 为什么 |
|---|---|---|
| Enable 3D | **开** | 底模要能放在 3D 空间里 |
| Position | Separate 或 3D Path 都行 | 读矩阵，两种都一样 |
| Rotation | **Euler Angles** | 数字好读；四元数也行，没影响 |
| 缩放 | 等比（XYZ 一样） | 非等比会让旋转歪掉 |

  **建议**：底模建好后不要再动它。角色和相机相对它走。

### 角色（`character` 上面的 Peg）

| 项 | 设置 | 为什么 |
|---|---|---|
| Enable 3D | **开** | 角色要立在 3D 空间里 |
| Rotation | **Euler Angles** | 同上 |
| Pivot | 一般留 0 | 除非你要绕别处转 |
| Ortholock | 按需 | 开了角色永远面朝相机（做转面时方便） |

### 相机

| 项 | 设置 | 为什么 |
|---|---|---|
| 父 Peg | **Enable 3D 开** | 相机要在 3D 里运动 |
| 父 Peg 旋转 | **Euler Angles** | 同上 |
| **Override Scene FOV** | **勾上**（要做 FOV 动画时） | 不勾读到的永远是场景默认值 |
| 默认相机 | `Scene   Camera` 里选中它 | 脚本读的是这台 |

## 三、导出（Harmony）

**两个脚本都不用选中任何节点。**

### 1. 导出相机

1. 打开 `Script Editor`；
2. 粘贴 `tools/TB_ExportMatrix.js`；
3. Run；
4. 存成 `camera.json`。

### 2. 导出角色

1. 粘贴 `tools/TB_ExportCharacter.js`；
2. Run；
3. 存成 `character.json`。

### 导出前检查

- [ ] 底模节点叫 `model`
- [ ] 角色节点叫 `character`
- [ ] `Scene   Camera` 里勾的是要用的那台
- [ ] 相机 Peg 的 `Override Scene FOV` 按需勾选

---

## 四、导入（Blender）

### 顺序不能反

```
1) File   Import   Harmony Camera   → 选 camera.json
2) File   Import   Harmony Character → 选 character.json
3) File   Export   Light Data (.json) → 存 light.json
```

**角色必须在相机之后**（影子平面按相机算尺寸）；
**光最后导**（要读角色代理的位置）。

### 导入后检查

- [ ] 相机在动（拖时间轴）
- [ ] 场景里出现 `TB_CharProxy` 和 `TB_CharShadow`
- [ ] 场景 fps / 分辨率自动变成了 JSON 里的值
- [ ] `light.json` 里有你所有灯的条目（key / fill / rim）

## 五、影子（接触阴影）

导入角色时，Blender 会建**两个东西**：

| 物体 | 是什么 | 用途 |
|---|---|---|
| `TB_CharProxy` | 空物体 | 标记角色的位置/朝向（算光用） |
| `TB_CharShadow` | 平面 | 贴着角色图，**只投阴影，不进画面** |

**为什么不直接投**：Blender 里没有角色，只有一张 2D 图。所以要用**一张贴着角色图的平面**来代替它挡光——
**alpha 决定影子轮廓**，投出来的就是角色的形状。

### 用的时候

1. 导入角色时，在导入面板里按 **`N`**，填「角色图」；
2. 平面会按相机 FOV 自动算尺寸（铺满画面），一般不用调；
3. 地面要能接影子；
4. 渲出来的环境里就**带着角色的影子**了。

### 角色图必须**只含角色**

| 图 | 结果 |
|---|---|
| 角色单独渲染（透明背景） | ✅ 小马形状的影子 |
| 整个画面（角色 + 树 + 地形） | ❌ 影子是**树和地形**的大黑块 |

**所以 TBH 输出时用「只画角色」的那条 Write 分支**（`final`），不要用整幅画面。

### 影子的大小 ≠ 角色大小

影子会被**拉长**——灯越低越长：

```
影子长度 ≈ 角色高度 ÷ tan(灯的仰角)
```

| 灯仰角 | 影子 |
|---|---|
| 80° | 很短 |
| 45° | ≈ 1 倍身高 |
| 30° | ≈ 1.7 倍身高 |

**这是物理正确的。** 觉得难看就抬高灯，或降低影子浓度。

### 平面尺寸有依据，别乱拉

```
width  = 2 × 距离 × tan(水平FOV/2)
height = width / 宽高比
```

目的是**让平面正好铺满画面**，这样图上的 alpha 和角色屏幕位置一一对应。

**拉大/拉小 → 影子变大变小、位置偏。**

### 角色图用什么格式

| 格式 | 效果 |
|---|---|
| **`.mov`（带 alpha，ProRes 4444）** | ✅ **逐帧动画**，跟着时间轴播 |
| `.exr` / `.png`（单帧） | 静态影子，角色不动时够用 |

  **为什么不用 EXR 序列**：Blender 的 Python API 认不了序列帧
  （`source='SEQUENCE'` 不生效，`reload()` 会崩）。
  MOV 反而原生支持——**要动画就导 MOV**。

### 前提

- **角色图要先渲出来**：所以顺序是「先渲角色 → 再渲环境」；
- MOV 必须**带 alpha**（ProRes 4444），否则影子是整块矩形。

### 导入时可以关掉

插件里有个「创建影子代理」的勾，不需要就取消。

## 六、常见问题

| 现象 | 原因 | 解决 |
|---|---|---|
| 「找不到底模节点 Top/model」 | 图层没改名 | 把 3D 模型那个 Drawing 改名 `model` |
| 「找不到角色节点 Top/character」 | 同上 | 把角色层改名 `character` |
| 「找不到相机」 | 场景没有相机 | `Insert   Camera` 加一个 |
| 角色位置不对 | 底模矩阵没带 | 用新版 `TB_ExportCharacter.js`（自带底模） |
| **影子是整块矩形** | 平面没贴图，或图没 alpha | 填「角色图」；确认图带 alpha |
| **影子是树/地形** | 用的是**整幅画面**的图 | 换成只含角色的图 |
| **影子太大/太小/偏移** | 手动改过平面缩放 | 删掉平面重新导入（自动尺寸） |
| **影子不跟着角色动** | 用的是单帧图 | 换成带 alpha 的 MOV |
| 相机不动 | JSON 是旧的 / 导错文件 | 重新导出 |

## 七、名词对照

| 词 | 意思 |
|---|---|
| **底模 / 代理** | 从 Blender 导进 Harmony 的简化 3D 模型，给动画师当空间参照 |
| **AOV** | 分开渲染的通道（颜色、法线、深度…） |
| **法线图** | 每个像素记录「这个面朝哪」，用来重打光 |
| **代理（TB_CharProxy）** | Blender 里代表角色位置的空物体，不参与渲染 |
| **影子代理（TB_CharShadow）** | 贴着角色图的平面，只投阴影、不进画面 |
| **light.json** | 每帧的光方向/颜色/距离，给 AE 打光用 |
